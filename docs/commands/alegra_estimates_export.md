## alegra estimates export

Export all estimates to CSV or JSON

### Synopsis

Fetch every page of estimates and write them to a file (or stdout).

```
alegra estimates export [flags]
```

### Examples

```
  alegra estimates export > estimates.csv
  alegra estimates export --format json --out estimates.json
  alegra estimates export --param status=open
```

### Options

```
      --format string       Export format: csv or json (default "csv")
  -h, --help                help for export
      --out string          Write to this file (default: stdout)
      --param stringArray   Filter by an API query parameter: key=value (repeatable)
  -q, --query string        Free-text search
```
