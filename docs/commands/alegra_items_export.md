## alegra items export

Export all items to CSV or JSON

### Synopsis

Fetch every page of items and write them to a file (or stdout).

```
alegra items export [flags]
```

### Examples

```
  alegra items export > items.csv
  alegra items export --format json --out items.json
  alegra items export --param status=open
```

### Options

```
      --format string       Export format: csv or json (default "csv")
  -h, --help                help for export
      --out string          Write to this file (default: stdout)
      --param stringArray   Filter by an API query parameter: key=value (repeatable)
  -q, --query string        Free-text search
```
